# Работа с сайтом

Основной справочник теперь встроен в админку: **Помощь менеджеру** в боковом
меню и на стартовом экране, адрес `/admin/help`. В списках и редакторах есть
пояснение раздела и ссылка на соответствующую главу в новой вкладке, чтобы
можно было читать её, не закрывая несохранённую работу.

В справочнике описаны все разделы, четыре вкладки общих настроек, работа с
черновиками, оба вида предпросмотра, публикация, файлы и частые ошибки.
Текст встроенной справки находится в `app/src/cms/help/`; ниже — краткая памятка.

1. Откройте `/admin` и войдите. На обзоре есть быстрые переходы к главной,
   продукции, проектам, общим данным и медиатеке.
2. Откройте материал или нажмите «Создать». Заполните название. В обычном
   материале добавьте краткое описание и главное фото перед публикацией.
3. Добавьте нужные блоки. Перетаскивайте строки для порядка, снимайте «Показывать
   блок», если раздел временно не нужен. Фото, выбранное из медиатеки, можно
   использовать повторно.
4. Нажмите «Сохранить черновик». Работающий сайт продолжит показывать прежнюю
   опубликованную версию. Незавершённую новую страницу посетители не увидят.
5. Откройте «Предпросмотр»: рядом доступны отдельное окно и встроенный просмотр
   с размерами телефона, планшета и десктопа. Предпросмотр требует входа.
   После следующего сохранения черновика просмотр обновляется.
6. Когда всё проверено, нажмите «Опубликовать изменения». Чтобы уйти из просмотра
   черновиков, воспользуйтесь ссылкой «Выйти из предпросмотра» в верхней полосе.
7. Предыдущие варианты находятся во вкладке «Версии». Перед восстановлением
   проверьте дату, текст и статус: восстановление опубликованной версии может
   сразу изменить сайт. После восстановления проверьте статус и предпросмотр.

## Тема и размер текста

В верхней панели есть два компактных элемента без надписей:

- **Переключатель с солнцем/луной** — слева светлая тема, справа тёмная.
  Одно нажатие меняет тему. Пока вы не выбрали тему вручную, она следует настройкам устройства.
- **Кнопка T ↕** — каждое нажатие переключает размер: обычный → увеличенный →
  крупный → снова обычный. Три отметки под иконкой показывают текущую ступень.

Подсказка при наведении на кнопку размера сообщает текущий и следующий размер.
Изменения видны сразу, без окон и выпадающих списков. Увеличивается текст,
а ширина страниц и отступы остаются прежними. Из-за переносов текста блоки
могут стать выше — это нормально.
С клавиатуры: Tab до нужного элемента, Enter или пробел для переключения.

Выбор сохраняется в этом браузере после перезагрузки. Настройки сайта и админки
независимы. Содержимое материалов не меняется, публикация не нужна,
несохранённые поля остаются на месте.

## Что где менять

| Задача | Раздел |
|---|---|
| Баннер, описание компании на главной, услуги и этапы | Страницы → Главная |
| Информация о компании, дополнительная страница | Страницы |
| Фото и описание изделия | Продукция |
| Описание направления | Услуги |
| Кейс с задачей, решением и результатом | Реализованные проекты |
| Телефоны, офисы, логотипы, меню и подвал | Общие данные сайта |

Форма связи и страница политики отключены. Для связи посетители используют
телефоны, email и мессенджеры на странице «Контакты».

## Фото и видео

Загрузите файл в «Фото и видео», укажите понятное название и описание изображения.
Обработка выполняется автоматически при работающем worker: дождитесь «Готово».
До этого публикация материала с файлом будет отклонена с пояснением. Для видео
с речью можно вставить подготовленные субтитры WebVTT. Исходный файл сохраняется.

При ошибке убедитесь, что исходник открывается, соответствует показанным лимитам,
и нажмите «Повторить обработку исходника». Если долго остаётся «Ожидает», попросите
администратора проверить worker. Для замены загрузите новый файл и выберите его
в материале: старая опубликованная версия сохранит свой исходник.

Неиспользуемый файл можно архивировать. Файл из опубликованного материала сначала
замените или уберите в материале, затем опубликуйте изменение. Удаление материала
доступно владельцу; для временного снятия воспользуйтесь отменой публикации.

## Пользователи

Владелец создаёт учётные записи менеджеров и задаёт роли. Менеджер не может повысить свою роль. Восстановление пароля по email требует настроенной исходящей почты; пока её нет, обратитесь к владельцу.

Форма, архив обращений и настройки уведомлений удалены: посетители связываются по контактам компании. Служебные настройки владельца показывают состояние подключений и не требуют заполнения менеджером.
