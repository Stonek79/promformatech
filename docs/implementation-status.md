# Состояние реализации — 30.10.2026

Сайт и Payload работают на SQLite. Публичная форма, архив заявок, уведомления о заявках, rate-limit storage и схемы формы удалены. PostgreSQL, Docker Compose и импорт старой базы больше не входят в приложение. Старые локальные данные не удалялись.

Сохранены страницы, продукция, услуги, проекты, медиатека, роли владельца/менеджера, черновики, версии, предпросмотр, публикация, адаптивность, темы, размеры текста и справочник.

Добавлены исходная SQLite-миграция, WAL/busyTimeout, хранение блоков JSON, файловая блокировка worker, standalone и CLI-поставка, GitHub Actions для Linux x64, шаблоны systemd/Nginx, согласованные копии и процедура обновления. На VPS код не собирается и npm-зависимости не устанавливаются.

Актуальные команды: [VPS](deployment/native-vps.md), [домашний стенд](deployment/home-server.md). Статус проверок и ограничения: [отчёт перехода](reviews/2026-10-30-native-sqlite.md).

До запуска нужны сам VPS/домен, настройка DNS/TLS, внешний backup и проверка восстановления, проверка systemd/обновлений и замеры памяти на Linux, приёмка наполнения менеджером. Наличие подготовленного кода не означает, что эти операции уже выполнены.
