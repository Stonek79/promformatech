# Unbounded

Шрифт исходного сайта сохранён локально с кириллицей и латиницей.
Источник: `ofl/unbounded/Unbounded[wght].ttf` официального репозитория
<https://github.com/google/fonts>. Исходная поставка ссылается на commit
`f3ec43228a864a72487e41552e2140efab9884ea` проекта
<https://github.com/googlefonts/unbounded>.

TTF преобразован в WOFF2 без удаления символов; соответствие таблицы символов
проверено FontTools. Лицензия SIL OFL 1.1 сохранена в `Unbounded-OFL.txt`.

Файл подключён через `next/font/local` и раздаётся нашим приложением.
Geist из стартового шаблона удалён, поскольку в исходном дизайне используется
Unbounded. Дополнительных зависимостей для шрифтов в приложении нет.
